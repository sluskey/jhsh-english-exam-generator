# 國中英語文 108 課綱素養命題與自動化產卷技能 (jhsh-english-exam-generator)

本技能 (Skill) 專門用於指導 Google Antigravity 等 AI 代理人進行國中英語科段考自動化命題，生成完全符應「新北市立錦和高級中學」國中部試務規範、**教育部《十二年國民基本教育課程綱要—語文領域-英語文（108 課綱）》**、臺師大心測中心「國中教育會考 (CAP)」與 CEFR A2 語言指標之正式試題卷、答案詳解卷（含英聽錄音逐字稿）與命題審題檢核表。

---

## ✨ 五大核心亮點

1. **完整內建「教育部 108 英語文課綱」與「7～9 年級防超綱紅線系統」**：
   - 內建國中第四學習階段（`英-J`）三面九項核心素養、五大構念學習表現（`1/2/3/4/5-IV` 聽說讀寫綜合能力）與學習內容（`Ab/Ac/B/C/D-IV` 字彙、句型、溝通功能、文化、思考能力）。
   - **嚴格執行各年級語法階梯與防超綱紀律**：自動攔截舊課綱與高中超綱文法（7 年級不考過去/未來式與從屬子句；8 年級不考被動語態、完成式與關代；9 年級嚴禁出現分詞構句、倒裝句、虛擬法與非限定關代）。
2. **教育部 1200/2000 常用字彙與 CEFR A2 難度驗證引擎**：
   - 全卷用字嚴格對齊教育部常用 1200/2000 單字表與 CEFR A2 基礎級指標，超出範圍之專有名詞與進階生詞自動在文章末尾加註中文。
3. **心測中心國中教育會考 (CAP) 閱讀理解與生活圖表評量架構**：
   - 涵蓋「連續性文本」與「非連續性生活圖表（海報、菜單、時刻表、資訊圖）」，融合資訊擷取、統整解釋與反思評鑑三大閱讀層次。
4. **標準聽力測驗錄音逐字稿 (Listening Scripts) 自動生成**：
   - 完整支援「辨識句意」、「基本問答」、「言談理解」三大聽力題型，解析卷內建標準角色標記、題目問句、播音次數與停頓秒數指引。
5. **錦和高中標準排版與獨立三份 Word 檔案輸出**：
   - 一鍵產出符合錦和高中格式之 **三份獨立 Word (.docx) 檔**：試題卷（含手寫作答區與短選項橫排）、答案與詳細解析卷（含英聽腳本與手寫給分規準）、命題審題雙向細目檢核表。

## 📦 如何安裝本技能

### 方式 A：全域安裝（推薦，所有專案與新對話皆可隨時調用）

#### 透過 Git 指令安裝：
- **Windows (PowerShell)**:
  ```powershell
  git clone https://github.com/sluskey/jhsh-english-exam-generator.git "$HOME\.gemini\config\skills\jhsh-english-exam-generator"
  ```
- **macOS / Linux**:
  ```bash
  git clone https://github.com/sluskey/jhsh-english-exam-generator.git ~/.gemini/config/skills/jhsh-english-exam-generator
  ```

#### 手動複製安裝：
將 `jhsh-english-exam-generator` 資料夾複製至個人全域設定目錄：
- **Windows**: `C:\Users\<使用者名稱>\.gemini\config\skills\jhsh-english-exam-generator\`
- **macOS / Linux**: `~/.gemini/config/skills/jhsh-english-exam-generator/`

---

## 🚀 快速開始：提詞範例 (Prompt)

安裝完成後，在對話框中輸入 `/jhsh-english-exam-generator` 並提供段考規格參數：

```text
請使用 /jhsh-english-exam-generator 技能為我生成一份國中英語科段考試卷，規格參數如下：
1、年級、版本與範圍：八年級下學期 康軒版 第 1 課至 第 2 課（含 Review 1）。
2、題型與配分：總分 100 分
   - 第一部分：聽力測驗（辨識句意 3 題、基本問答 4 題、言談理解 3 題，共 10 題，每題 2 分，共 20 分）
   - 第二部分：綜合測驗（單題 15 題，每題 2 分，共 30 分，涵蓋核心字彙與當次語法句型）
   - 第三部分：克漏字與素養閱讀題組（克漏字 1 組 4 題、生活素養閱讀 2 組共 8 題，共 12 題，每題 2.5 分，共 30 分，含 1 組圖表海報題）
   - 第四部分：非選擇題（文意字彙 5 題每題 2 分、依提示作答/改寫 2 題每題 3 分、中翻英 1 題 4 分，共 20 分，附手寫作答卷）
3、難易程度：難易適中（預估平均通過率約 60%～65%，文法概念清晰，閱讀篇章具推論深度）。
4、用字規範：嚴格遵循教育部 1200/2000 常用字彙與 CEFR A2，超出範圍生詞於文末加註中文。
5、輸出要求：輸出錦和高中標準 3 份獨立 Word 檔（試題卷、含完整英聽錄音稿之答案解析卷、命題審題檢核表）。
```
